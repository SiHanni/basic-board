#### 좋아요 기능은 동시성에 취약하다

- 같은 유저가 같은 게시글을 매우 빠르게 두 번 클릭하면
- INSERT 시도가 2번되어서 유니크키 에러가 발생할 수 있고
- 여러 요청이 거의 동시에 들어오면 좋아요를 눌렀는데 취소로 바뀌는 경쟁 상태도 발생할 수 있다.
- 그래서 토글 기반을 통해서
- 먼저 findOne으로 상태를 확인하고 업데이트 트랜잭션 범위 안에서 create/delete를 처리한다
- 그러면 유니크키 에러도 캐치가 가능하다.
- 정리하면 상태를 기준으로 순차적으로 검사를 끝마치고 상태 변경을 하는 패턴으로,
- 정합성 유지와 동시성 오류 방어를 고려한 것이다.
- 프론트입장에서 버튼 1개로 처리하는 UI를 같이 고려해준 것이다.
